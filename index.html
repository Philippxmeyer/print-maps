Print Maps

High-resolution maps in the browser, for printing.

0–30 mm gemeinsame Kartenfläche zwischen benachbarten Blättern (Standard: 15 mm); zusätzlich 10 mm weißer Rand für Schnitt- und Passmarken. Die Vorschau zeigt das gesamte Kartenraster; gelbe Streifen markieren die gewählte Überlappung.

Zusammensetzen: von links nach rechts, dann von oben nach unten. An inneren Verbindungen den linken bzw. oberen weißen Rand an den Schnittmarken abschneiden. Kartenstreifen um den gewählten Wert überlappend auflegen; bei 0 mm die Kartenkanten bündig aneinanderlegen und die weißen Ränder als Klebelaschen unterlegen. Gleiche Passkreuze deckungsgleich ausrichten. Außenränder am Schluss abschneiden. PDF mit 100 % / tatsächlicher Größe einseitig drucken.



Lokaler Mercator-Maßstab am Kartenmittelpunkt, ohne perspektivische Neigung.

Für den angegebenen Maßstab mit 100 % / tatsächlicher Größe drucken.

Required Attribution

Attribution of maps is required. Per the Mapbox attribution requirements:

Static and print maps need to be attributed in the same fashion as you would cite a photograph: in a textual description near the image.

If you can include HTML, use this code snippet that includes links to Mapbox & OpenStreetMap:

© <a href='https://www.mapbox.com/about/maps/'>Mapbox</a> © <a href='https://www.openstreetmap.org/copyright'>OpenStreetMap</a> <strong><a href='https://www.mapbox.com/map-feedback/' target='_blank'>Improve this map</a></strong>

For print output or if you can’t include links, use this text-only attribution:

© Mapbox, © OpenStreetMap
